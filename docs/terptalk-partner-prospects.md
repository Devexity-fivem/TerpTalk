## Creator Strategy (existing system — no new build needed)

**Live today:** `/youtubers` · `/youtubers/apply` · `/api/youtubers` ·
`/admin/youtubers` · `Profile.youtubeChannelUrl` · Verified YouTuber
badge.

**Already works:** a creator can run a public TerpTalk diary as the
companion to a video series, link its discussion thread, record the
harvest, and feed strain knowledge — no engineering required.

**Future sponsored creator campaigns** would need only:
- a sponsorship label on diaries/threads (small schema/UI change — later)
- a lightweight campaign/outcome summary for the sponsor (can start as
  a manually assembled report)

Both are deferred until there's a real creator + a real sponsor.

## Claim Safety (media kit discipline)

Every metric is labeled VERIFIED or PROJECTION. Current honest state:
tiny real population, working product, live affiliate infrastructure.
Never present expected CTR, projected revenue, or projected audience as
measured performance. When real numbers arrive (post-cohort), update the
kit with measured values.
